# Final Bootcamp Review

## My Readiness Level

I followed the GoMyCode full-stack web developer bootcamp. I feel that I am still improving, but I am ready to start a first experience in web development. I can build REST APIs with Express, work with MongoDB and Mongoose, and set up a connection to a remote database. I also know that I still need to become more independent with deployment and with debugging connection errors.

## Skills Acquired

- Node.js and Express: creating routes, middlewares, and REST APIs (GET, POST, PUT, DELETE)
- MongoDB with Mongoose: models, CRUD queries, and connecting to MongoDB Atlas
- Scrum methodology: roles, ceremonies, artifacts, and principles
- Professional preparation: CV, LinkedIn profile, and technical interview preparation
- Cloud and deployment: basics of cloud services and going to production

## Reflections

This bootcamp taught me to read error messages and look for the cause before changing code at random. The hardest part was connecting to MongoDB Atlas, which took several attempts before it worked. For the next step, I want to find an internship or a first job in web development, and keep working on my personal projects, such as my car rental website.
